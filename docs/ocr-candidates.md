# OCR error candidates

Generated by `scripts/find_ocr_candidates.py`; do not edit by hand.

- The list is **heuristic**: it marks spots that look suspicious, and **false positives are expected** (legitimate Sanskrit transliteration, German titles, and unusual abbreviations all trip some rules).
- It is a list of candidates for review, **not corrections**. The data (`data/source/*.csv`, `data/ewaia.json`, `bib/web/ewaia.json`) is not modified.
- Line numbers are physical line numbers in the CSV file (line 1 is the header). Edge and repeated spaces are shown as `␠`.
- Regenerate with `python3 scripts/find_ocr_candidates.py`. The output has no timestamp, so regenerating unchanged data gives no diff.
